# OPD 何时有效、何时失效

OPD 的成败很大程度上不取决于实现细节，而取决于**教师和学生之间的关系**，以及**教师信号在学生轨迹上是否可靠**。这一页把相关发现串起来。

## OPD 在学什么：复刻分布，不是学高分

Rethinking OPD（2604.13016）的核心结论可以概括为：**OPD 不是在学教师的高分，而是在复刻教师的概率分布模式。** <span class="verified">✅</span>

最有说服力的是一个**反向蒸馏实验**：把已经经过 RL 训练的 JustRL-1.5B 当学生，不管用 RL 之前的 1.5B 当教师，还是用分数略高的 7B 当教师，学生都**退回了 RL 之前的水平**。也就是说，OPD 的结果和教师的 benchmark 分数可以完全脱钩。

由此得出 OPD 成功的两个前提。

### 前提一：思维模式兼容

- 学生 Qwen3-1.7B-Base，用 Base 模型经 GRPO 训练出的 Qwen3-4B-Base-GRPO 当教师，效果**好于** benchmark 分数更高的 Qwen3-4B（non-thinking）；
- 原因是前者和学生同源，训练初期两者高概率 token 的重叠率更高；
- 早期由思维模式错位造成的损失，后期很难弥补。

### 前提二：教师要有增量知识

- 同源放大（比如 DeepSeek-7B 教 1.5B，或 Qwen3-4B 教更小的同系列模型）只是参数和数据更多，两者在局部的分布几乎一样，蒸馏收益很小；
- 经过额外 RL、真正注入了新能力的教师（如 Skywork-7B、Qwen3-4B-Math-RL）才能带来明显收益。

**兼容性决定学生学不学得进去，增量知识决定能学到多少。**

## 机制：交集 token 上的"飞轮"

Rethinking OPD 用三个指标追踪训练过程 <span class="verified">✅</span>：

| 指标 | 含义 | 成功的 OPD | 失败的 OPD |
|---|---|---|---|
| Overlap Ratio | 师生各自 top-k token 的交集比例 | 从约 72% 稳步升到 91% 以上 | 一开始就停滞 |
| Overlap-Token Advantage | 交集 token 上两者分布的对齐程度 | 趋近 0 | 停滞 |
| Entropy Gap | 学生轨迹上师生熵差的绝对值 | 缩小 | 停滞 |

这形成了一个飞轮：

```mermaid
flowchart LR
    A[交集扩大] --> B[梯度更干净、更稳定]
    B --> C[学生更像教师]
    C --> A
```

如果一开始思维模式错位、交集太小，飞轮就转不起来。这就是为什么要先用 SFT 预热：SFT 能提高初始的重叠率、缩小熵差。

NVIDIA 的 Semi-OPD 研究（2610.11291）从另一个角度印证了这一点 <span class="unverified">⚠️</span>：在 17 组师生组合里，只有当师生输出 token 的重叠率很高时，标准 OPD 才优于"只用初始学生 rollout 离线蒸馏"的做法，见[效率优化](../frontier/efficiency.md)。

## 教师在学生前缀上并不处处可靠

OPD 默认教师在学生走到的任何前缀上都能给出好的建议（和 DAgger 的假设一样），但实际并非如此。

### 越往后越不可靠

Rethinking OPD 的续写实验 <span class="verified">✅</span>：从学生回答的前 1K token 处让教师接着写，比学生自己接着写的准确率高约 **+0.37**；截到 16K 处时，优势只剩 **+0.02**。

扫描最大生成长度（0.5K 到 15K）也发现：3K 和 7K 最稳定，10K、15K 的效果见顶甚至回落，训练后期明显不稳定；高熵区域先在很靠后的位置出现，再逐渐向前扩散。

### 全局能分辨，不等于局部可利用

成功和失败的教师，在序列级别区分好坏回答的 AUROC 都在 0.73–0.75。失败的教师并不是分不清好坏，问题在于：它给出的**逐 token 信号方向互相冲突**，汇总成梯度时彼此抵消，有效梯度的模长很小。和学生思维模式相近的教师，局部信号更一致，学生也更容易利用。<span class="verified">✅</span>

### 学生出错之后，教师也会"接得上"

学生已经陷入重复、自我重置式推理，或者满篇标点和犹豫词时，教师仍会给这些局部"还能接上"的 token 较高的概率，代理信号于是被钻了空子。teacher-student log-prob 差的方差和极端值也随位置越来越大。（Revisiting OPD，2603.25562）<span class="verified">✅</span>

### 第一次犯错就失去背书

多轮智能体场景下，STRIDE（2609.14636）发现：有效的监督集中在每一轮的前缀部分，学生**第一次做出错误动作时，教师的背书就消失了**。<span class="unverified">⚠️</span>

### 局部可教性塌缩

"Prefix Teach, Suffix Fade"（2605.13643）把这个现象称为 **local teachability collapse**：轨迹后段的师生 advantage 仍然不为 0，但已经缺少能指导学习的局部对比。他们用变点检测找到教师信号失效的位置，只监督之前的部分，在 Qwen3 学生上比全轨迹 OPD 效果更好，域外能力也保持得更好。<span class="unverified">⚠️</span>

## sampled-token 奖励的结构性失衡

Revisiting OPD 统计第一个 iteration 的师生概率发现：学生采样到的大部分 token 拿到的是**负**奖励，学习信号集中在少数"局部看起来有利"的 token 上，训练对填充词、犹豫词和短续写特别敏感。<span class="verified">✅</span>

原因在于 $r_t$ 是相对量：学生采样到的 token 往往正是学生自己最自信的那个，学生概率高于教师的情况更常见。

## 容量差距

教师和学生差距太大时，学生吸收不了教师的信号：

- Hugging Face 用 Qwen3-4B 分别从 30B-A3B 和 235B-A22B 蒸馏，235B 教师强约 10 分，学生最终水平却差不多；用 235B 教师时，GPQA-Diamond 在第 40 步之后下降约 10%。<span class="verified">✅</span>
- SOD（2605.07725）：0.6B 学生从 4B 教师换成 14B 教师，平均分反而下降。<span class="unverified">⚠️</span>
- Busbridge et al.（2025）：过强的教师会让学生吸收信号的能力饱和。<span class="unverified">⚠️</span>

## 上限效应

散度最小化的目标就是"像教师"，所以 OPD 很难超过教师。MiMo-V2-Flash 的多教师 OPD 在大多数领域只追平或略超最强教师（多出来的部分来自叠加的结果奖励），在长程 Agent 和创意写作上还有回退，见[MiMo-V2-Flash](../cases/mimo.md)。

## 什么时候适合用 OPD：检查清单

- [ ] 学生已经能写出格式正确、能正常结束的轨迹（必要时先 SFT）
- [ ] 教师和学生用同一个 tokenizer，结束符等 special token 已对齐
- [ ] 教师有学生没有的能力（经过 RL 或专门训练），而不只是更大
- [ ] 教师和学生的思维模式兼容：开训前测一次 top-k 重叠率
- [ ] 尺寸差距适中（经验上 2–5 倍，或同尺寸的专家模型）
- [ ] 轨迹长度可控，或者有办法处理后段信号失真（截断、加权、提前停止）
- [ ] 想超越教师时，准备好结果奖励或后续的 RL 阶段

具体怎么做，见[标准配方](../practice/recipe.md)和[踩坑大全](../practice/pitfalls.md)。

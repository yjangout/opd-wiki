# 开放问题

整理自两篇 2026 年的综述和研究议程 <span class="unverified">⚠️</span>：

- [A Survey of On-Policy Distillation for Large Language Models](https://arxiv.org/html/2604.00626v3)（2604.00626）
- [A Formula-Driven Survey and Research Agenda for On-Policy Distillation](https://arxiv.org/html/2606.22793v1)（2606.22793）

以及本站其他页面里出现的未解决问题。

## 1. OPD 的 scaling law

- 学生多大、教师多大、on-policy 数据要多少，三者怎样分配算力？
- 达到某个质量所需的最少 on-policy 数据量是多少？
- 能否像预训练一样，事先预测 OPD 的收益？

## 2. 稠密信号和稀疏奖励怎么结合

- 逐 token 的教师信号和整条轨迹的结果奖励，权重怎么定？是固定比例、退火，还是按位置动态调整？
- 学生接近教师之后，怎样平滑地把主导权交给结果奖励？
- 教师在某些位置"指导出错"时，怎样用奖励来纠正（Reward-Aligned OPD，2608.27960）？

## 3. 长上下文与长程任务的信用分配

- 百万 token 级的上下文里，怎样做信用分配？
- 怎样可靠地检测"教师信号已经失效"的位置？
- 多轮智能体里，学生第一次出错之后的部分该怎么处理？

## 4. 教师在学生状态上的可靠性

这是 OPD 区别于 DAgger 的根本问题。综述把 OPD 的失败归纳为几类：

- **局部教师噪声**：教师在单个位置上的信号不可靠；
- **覆盖随长度衰减**：越往后，教师越不熟悉学生走到的状态；
- **短视的逐 token 监督**：$\gamma = 0$ 忽略了当前 token 对后续状态的影响；
- **偏差与方差的取舍**：序列级无偏但方差大，逐 token 方差小但有偏。

## 5. 跨 tokenizer 蒸馏

不同模型家族之间怎样做稳定、高效的 OPD？见[新场景](new-domains.md)。

## 6. 多模态 OPD 的理论

跨模态 OPD 目前只有早期的实证工作，理论基本空白。

## 7. 和 RL、自蒸馏的边界

- OPD 本质上是"只有 KL 项、参考模型换成教师"的 RL。两者的统一框架是什么（G-OPD、LSPD 等）？
- 自蒸馏里的特权信息到底贡献了多少？怎样避免 privilege illusion？
- 混合自蒸馏和在线稳定化，被认为是下一步的方向。

## 8. 什么时候真的需要 on-policy

Semi-OPD 发现，在多数师生组合上，只用初始学生的 rollout 离线蒸馏就更好，只有师生高度兼容时在线 OPD 才占优。on-policy 的必要性边界在哪里？见[效率优化](efficiency.md)。

## 9. 超越教师

散度最小化的上限是教师。"OPD + 结果奖励"、"学生再 RL 成为新教师"（共同进化）等路线，怎样系统地突破这个上限？

## 10. 复现性与报告规范

2606.22793 提出了一份最低限度的报告清单。结合本站的经验，一篇 OPD 论文至少应该说明：

- [ ] 学生和教师的具体模型、tokenizer 是否相同
- [ ] 散度方向和估计粒度（sampled-token / top-K / 全词表），loss 的具体写法
- [ ] 折扣因子、是否叠加结果奖励及其权重
- [ ] rollout 的采样参数（温度、top-p、最大长度）
- [ ] 是否 mask special token、EOS 怎么处理
- [ ] SFT 预热用了什么数据
- [ ] 和基线对比时控制的是步数还是 GPU 小时
- [ ] 评测的采样参数和重复次数
- [ ] 域外能力的变化

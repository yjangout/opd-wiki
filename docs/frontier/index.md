# 变体与前沿

截至 2026 年 11 月，社区围绕 OPD 的研究大致分成下面几条线。

| 方向 | 要解决的问题 | 页面 |
|---|---|---|
| Agentic OPD | 多轮智能体任务里的信用分配；学生走错之后教师信号失效 | [Agentic OPD](agentic.md) |
| 多教师 OPD | 把多个领域专家合并成一个模型，避免跷跷板；教师之间的冲突 | [多教师 OPD](multi-teacher.md) |
| 自蒸馏 | 没有外部教师时怎么办；把上下文、经验、特权信息内化进权重 | [自蒸馏](self-distillation.md) |
| 黑盒教师 | 教师是闭源 API，拿不到 logits | [黑盒教师](black-box.md) |
| 效率 | 学生 rollout 和教师打分太贵；是否真的需要每一步都 on-policy | [效率优化](efficiency.md) |
| 新场景 | 多模态、量化、安全对齐、扩散语言模型、跨 tokenizer、弱教强 | [新场景](new-domains.md) |
| 理论与稳定性 | OPD 与 RL 的统一、失败模式、方差 | [开放问题](open-problems.md) |

## 2026 年下半年值得关注的工作

| 工作 | 一句话 |
|---|---|
| Semi-OPD（2610.11291，NVIDIA） | 学生 rollout 只生成一次、教师 logprob 只算一次，反复复用；17 组师生组合中 14 组优于标准 OPD |
| State-OPD（2610.13238） | 多轮智能体：在高熵的交互状态上采样多个完整回应，以状态为基础给出教师监督 |
| STRIDE（2609.14636） | 多轮智能体：教师累计 logprob 过低时提前停止，从最弱的正确轮次重新开始 |
| LSPD（2609.35505） | 把 OPD 看作 KL 正则 RL，引入价值方法的乐观探索和离线数据复用 |
| Reward-Aligned OPD（2608.27960） | 教师指导出错时，用奖励来纠正 |
| When EOS Tokens Disagree（2609.20511） | 揭示长度暴涨的一个根源：师生的结束 token 不一致 |
| 量化 OPD（2609.26708） | 让低比特模型在自己会走到的状态上蒸馏 |
| Edit, Don't Imitate（2610.30231） | 多模态推理：只对出错的地方做最小编辑式的纠正 |

（以上多数只读到摘要 <span class="unverified">⚠️</span>，细节以原文为准。）
